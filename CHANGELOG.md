## [Unreleased]

### Added

- `AuthContext`: one authentication context per tenant, usable as an Azure SDK
  `TokenCredential` (`auth`) and `AsyncTokenCredential` (`auth.aio`).
- User sign-in through the browser or the Windows broker, and app sign-in with a client
  secret, a PEM/PFX certificate, or a non-exportable certificate in the Windows certificate
  store (client assertion signed PS256, with an RS256 fallback).
- Microsoft first-party client ids by default, with `client_id=` overrides on the context and
  on every client.
- In-memory token cache and an encrypted disk cache (`cache="disk"`, `cache_path=`). There is
  no unencrypted disk cache.
- `AuthContext.for_tenant()` for GDAP: customer-tenant tokens from one partner sign-in, never
  prompting.
- Async clients: `GraphClient`, `AzureClient`, `ExchangeClient`, `IppsClient` and
  `KeyVaultClient` (extra `keyvault`), with retries, claims-challenge handling and paging.
- Blocking clients in `azure_auth.sync`, generated by `scripts/generate_sync.py`.
- Exception hierarchy: `AuthError` and `ResourceError` with their subclasses.

### Removed

- The template command line entry point.
